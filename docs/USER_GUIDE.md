# PIP-Link 地面端使用指南

## 1. 连接机器人

打开“连接”页面后可以使用两种方式：

- 点击“扫描机器人”，通过 `_pip-link._udp.local` mDNS 服务发现机载端；
- 手动填写机载端 IP、控制端口和视频端口后直接连接。默认控制端口为 `6000`，视频端口为 `5000`。

连接建立后，地面端会主动读取一次机载端图传参数。链路重连或检测到机载视频会话重启时会重新同步，避免本地设置页与远端参数不一致。开启“自动重连”后，非手动断开导致的链路中断会按设置的间隔重试。

## 2. 第一视角与 READY

关闭设置页后进入第一视角画面。无视频时显示明亮的连接状态背景；收到有效视频帧后，图传会保持完整画布比例，不为导航或设置控件预留空间。

HUD 包括：

- 左下角键盘、鼠标按键、滚轮和鼠标移动预览；
- 右下角 FPS、码率、RTT 和丢包率；
- READY / NOT READY 状态。

只有控制链路和视频都可用时才能进入 READY。打开设置、打开开发者控制台、窗口失去焦点、视频超时或连接断开都会立即退出 READY，并停止发送有效控制输入。

## 3. 设置页面

设置页包含七个分类：连接、图传、控制、录制、诊断、日志和界面。图传参数修改采用 120ms 防抖，松开控件时立即提交；分辨率、窗口模式和显示器修改需要在 30 秒内确认，否则自动回滚。

“控制 → 键盘绑定”可以修改所有快捷键：

- 左键点击按键按钮后，再按一个键完成绑定；
- 点击同行的“清空”按钮解除绑定；
- 点击“取消本次绑定”只退出监听，不会把鼠标左键绑定进去；
- 新绑定与其他动作冲突时，冲突动作会自动解除绑定；
- “开始录制”可以和“暂停/继续录制”或“结束录制”共用同一个键；
- “暂停/继续录制”和“结束录制”不能共用同一个键。

当录制动作共用一个键时，当前录制状态决定唯一动作：空闲时开始录制，录制中执行暂停/继续或结束。同一次按键不会连续触发多个录制状态。

## 4. 默认快捷键

| 按键 | 动作 |
|---|---|
| `Esc` | 打开或关闭整页设置 |
| `F6` | 切换 READY |
| `Tab` | 显示或隐藏输入 HUD |
| `` ` `` | 打开或关闭开发者控制台 |
| `F9` | 开始录制 |
| `F10` | 截屏 |
| 未绑定 | 暂停/继续录制 |
| 未绑定 | 结束录制 |

旧版 11 项快捷键配置会自动补充新的媒体快捷键，不会覆盖原有控制键位。

## 5. 录像与截图

在“录制”页面使用系统目录选择器设置保存位置。相对目录默认位于 Windows“视频”目录下；绝对路径按原路径使用。

录像采集的是 D3D11 最终合成窗口，包括机器人画面、设置页面、HUD、控制台和录制用光标标识。顶部录制条会显示状态与时长，并提供暂停/继续和结束按钮。暂停期间不向编码器写入画面，继续后沿用同一文件且时间轴连续。

可选格式：

- H.264 MP4；
- H.264 MKV；
- FFV1 无损 MKV。

录像依赖 `ffmpeg.exe`，必须能从 `PATH` 找到。PNG 截图不依赖 FFmpeg；截图成功后屏幕边缘会播放蓝色渐变反馈动画，该动画不会写入截图文件。

## 6. 诊断、日志与控制台

诊断曲线保留最近 60 秒数据。日志列表在停留于底部时会随新日志自动滚动；手动向上查看历史后不会强制抢回位置。

开发者控制台支持：

```text
help
status
stats
reconnect
disconnect
export diagnostics
export log
clear log
version
```

控制台支持上下方向键浏览历史命令，并可拖动下边缘调整高度。

## 7. 本地数据

- 设置：`%LOCALAPPDATA%\PIP-Link\settings.ini`
- 审计日志：`%LOCALAPPDATA%\PIP-Link\audit.jsonl`
- 诊断和日志导出：`%LOCALAPPDATA%\PIP-Link`
- 录像和截图：录制页面选定的目录
